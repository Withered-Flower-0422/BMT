# MCP {#mcp}

## 插件下载 {#download}

点击 <a :href="withBase('/patches/maxider/mcp-bridge.zip')">下载 MCP 插件</a>。

## 插件安装 {#install}

::: tip 提示

请确保 BME 版本在 1.1.6 Maxider+ a4 以上。

:::

- 点击 BME 的 `菜单栏 → 设置 → 插件配置` 按钮
- 在弹出的窗口中点击 `安装 (zip)`，选择下载的 MCP 插件进行安装
- 点击 `启用` 以启用 MCP 插件
- 在 `配置` 中可以复制 _客户端地址_ 及 _令牌_，然后在自己使用的 AI 中进行 MCP 配置
- 完成配置后即可使用 AI 操作 BME
