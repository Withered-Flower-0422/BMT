# MCP {#mcp}

## Download {#download}

Click to <a :href="withBase('/patches/maxider/mcp-bridge.zip')">download MCP bridge</a>.

## Install {#install}

::: tip

Please ensure the BME version is above 1.1.6 Maxider+ a4.

:::

- Click BME's `Menu Bar → Settings... → Plugin Settings` button
- Click `Install (zip)` in the pop-up window, select the downloaded MCP plugin to install
- Click `Enable` to enable the MCP plugin
- Copy the _Client URL_ and _Token_ in the `Configure` section, and configure MCP in your AI
- Complete the configuration and you can use AI to operate BME
